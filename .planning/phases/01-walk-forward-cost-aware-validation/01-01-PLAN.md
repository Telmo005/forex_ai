| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Information Disclosure | MT5 demo credentials passed as CLI args | medium | mitigate | Credentials are for a demo (no real money) account; instruct the executor to never echo them into the SUMMARY or logs, and prefer env vars (MT5_LOGIN/PASSWORD/SERVER) over inline literals. |
| T-01-02 | Tampering | Synthetic data silently masquerading as real data for VALID-01 | high | mitigate | Task 3 checkpoint hard-gates on the human confirming real vs synthetic origin; the `revalidated_on_real_data` flag (plan 01-03) is only set true on a confirmed real-data run — never on synth. |
| T-01-03 | Spoofing | Placeholder cost values mistaken for real broker costs | medium | mitigate | Every placeholder value carries an inline "placeholder pending real symbol_info() data" comment and COST_MODEL_VERSION records the provenance; spec documents the calibration gap. |
| T-01-SC | Tampering | npm/pip/cargo installs | high | accept | No packages are installed in this phase — all libraries (scikit-learn, pandas, numpy, MetaTrader5) are pre-existing dependencies per RESEARCH.md Package Legitimacy Audit. Nothing to mitigate. |
